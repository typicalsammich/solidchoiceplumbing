# Solid Choice Plumbing

Static multipage website with centralized service content and a Node build generator.

## Run
- npm run build — generate pages and service illustrations
- npm run check — validate links, metadata, company identity and requested regressions
- npm run dev — preview at http://127.0.0.1:4173

No dependency installation is needed to build or serve the site. The dist directory contains the deployable website. Edit business.json, services.json and regions.json, then rebuild.
